PKC 本地服务 · 启动故障排查
========================================

一、先确认 ZIP 已经完整解压

不要在压缩软件的预览窗口里直接双击。
先右键 ZIP -> 全部解压，再进入解压后的文件夹。

文件夹里至少应该有这些内容：

  启动.bat
  start.bat
  server.mjs
  assets\
  director\
  bp-core\
  数据\

如果缺少 director 或 bp-core，服务会启动失败。


二、安装 Node.js

从 https://nodejs.org/ 下载 LTS 版本并安装。
推荐使用默认安装位置，不需要执行 npm install。

安装完成后：

  1. 关闭所有旧的命令行窗口；
  2. 重新双击 start.bat（或 启动.bat）。


三、正常启动时应该看到

  ==============================================
    PKC Data Chart - Local Server
  ==============================================

  Node.js:
  v20.x.x 或更高

  Starting: http://localhost:8971
  Keep this window open. Close it to stop the server.

  然后出现 PKC 本地服务的启动信息，浏览器自动打开。

这个命令行窗口必须一直开着。关掉它，服务就停止了。


四、常见提示

1. [ERROR] Node.js was not found

   Node.js 没有装好，或安装后系统的 PATH 还没刷新。
   重新安装 LTS 版，或者重启 Windows 后再试。

2. 端口 8971 已被占用

   可能服务已经在运行。先打开：

     http://localhost:8971

   如果能打开，就不用再启动第二个。
   如果打不开，关闭旧的命令行窗口后再启动。

3. 浏览器提示无法连接

   等服务窗口里出现“本地服务已启动”后，再刷新浏览器。

4. 窗口一闪而过

   请改用 start.bat，并保留窗口截图。


五、手动诊断

在解压后的文件夹空白处右键，选择“在终端中打开”
（或按住 Shift 右键 -> 在此处打开 PowerShell 窗口），运行：

  node -v
  node server.mjs

如果 node -v 能看到版本号，但上面的命令报错，
把窗口里的红字/报错内容截图发回来。
