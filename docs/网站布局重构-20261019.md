# 网站布局重构 · 2026-10-19

## 目标

把原本“生成器 6 个平铺标签 + 独立导播台 + OBS 页面”的结构，改成一条清楚的层级：

```
首页 → 数据工作台（系列赛 → 场次 → 局）→ 具体标签
     → 导播台（赛前 / 赛中 / 赛后场景）→ 当前场景操作
```

## 新结构

### 首页 `/`

- 当前工作卡片：系列赛、场次、局、双方、比分。
- 三个主入口：数据工作台、导播台、使用说明。
- OBS 四个浏览器源入口。
- 服务状态与第一次使用步骤。

### 数据工作台 `/generator`

- 顶部应用导航：数据工作台 / 导播台 / 说明。
- 固定上下文条：**系列赛 → 场次 → 局**，包含打开本场、新一局、交换红蓝。
- 标签按三组：
  - 数据：对局、赛程
  - 资料：队伍、英雄
  - 输出：导出
- 右侧预览可“收起 / 显示”，表格不再被固定 470px 挤压。
- 赛程页增加页内导航：分组 / 抽签 / 赛果 / 导出。
- 支持 `?tab=bracket` 等深链，首页“看赛程”直接落到赛程页。
- 在导播台 iframe 中以 `bare=1` 打开时，只保留上下文条和内容，隐藏重复的顶栏与标签。

### 导播台 `/director`

- 左侧导航分组：直播 / 数据 / 资料 / 输出 / 帮助，并有“首页”入口。
- 场景列表按赛前 / 赛中 / 赛后 / 其他分组。
- 右侧操作面板只显示当前场景对应的内容：
  - 赛间：倒计时 + 赛间板设置
  - 解说：解说演播厅（标题 / 两队 / 三位解说）
  - 赛程图：抽签直播
  - 数据图：轮播控制
  - 其他场景：通用说明
- 顶部保留“当前场次 · 局”上下文条和推送 / 丢弃。

### OBS

- 地址保持 `/obs/commentary`、`/obs/interval`、`/obs/bracket`、`/obs/chart`。
- 宽高仍为 1920×1080。
- BP / 阵容 / 巅峰对决三个场景已从导播台移除；旧 BP 代码保留在 `bp-core`，不再出现在界面。

## 兼容性

- 所有原有 URL 不变：`/generator`、`/director`、`/obs/*`。
- 数据文件仍在根目录 `数据\`。
- 素材仍在根目录同名文件夹（英雄图 / 音乐 / 直播素材），路径不变。
- 旧版 `director/director.html`、`build-console.mjs`、生成器备份保留在根目录，不参与运行。

## 场景调整（2026-10-19）

- 导播台场景从 7 个减为 5 个：**解说 / 赛间 / 赛程图 / 赛后数据图 / 空白**。
- 删除 **BP / 阵容 / 巅峰对决** 三个场景；BP 状态机代码仍保留在 `bp-core`，但不再出现在界面。
- 新增 **解说演播厅**：
  - 上半部分：赛事标题、副标题、两队圆形徽标与 VS；
  - 下半部分：演播椅、白色圆桌、解说 / 嘉宾席位；
  - 解说人数可选 1 / 2 / 3 位，椅子和姓名牌数量随人数变化；
  - 中央显示当前比分；解说阶段可选赛前 / 局间 / 赛后；
  - 左上角与背景加入赛事龙徽；
  - 队伍不显示圆形头像，只显示队名队牌；横幅同样不带头像；
  - 底部可弹「换人」或「赛事成就」横幅，内容由导播在右侧面板填写；
  - 右上角只显示 `LIVE · 解说席`，**没有倒计时**；
  - 队名跟随当前场次；解说姓名 / 身份在导播台右侧「解说画面」里编辑；
  - OBS 地址：`http://localhost:8971/obs/commentary`。

### 解说画面打磨记录（5 轮）

1. 座位改为 1–3 人动态布局，姓名牌随人数增减。
2. 椅子加入靠背、扶手、坐垫、椅腿、地面阴影；桌子加入桌面与前沿。
3. 增加 LED 背景框、顶部聚光、地面舞台与前景桌沿，拉开前后层次。
4. 每位解说加入头肩剪影、耳机弧线和麦克风，让席位更像真人坐席。
5. 横幅加入斜切轮廓、渐变、扫光、金色收边；换人用紫白，赛事成就用深蓝金，并补齐成就图标与选手标签。
6. 横幅改为纯叠加层：出现 / 消失只动横幅本身，解说姓名牌、椅子和桌子不做位移。

## 验证

- 首页当前工作卡显示真实系列赛 / 场次 / 局 / 比分。
- `/generator?tab=bracket` 正确落到赛程页。
- 预览收起 / 显示正常。
- 赛程页内导航可滚动到分组 / 抽签 / 赛果 / 导出。
- 导播台场景切换时右侧操作面板正确切换。
- 导播台内嵌生成器无横向溢出、无重复顶栏。
- 全部联动测试、OCR 测试、`verify-app`、`verify-kpl-style` 通过。
